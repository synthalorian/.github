An independent studio founded in 2026 by [synthalorian](https://github.com/synthalorian). We build open-source AI developer tools, forensics and privacy software, mesh networking, games and a game engine, a synthesizer, Linux and Android themes, and Skyrim mods.

---

## AI coding tools
| Repo | What it is |
|---|---|
| [openshield](https://github.com/synthalorian/openshield) | Open-source AI coding harness in Rust |
| [openshield-desktop](https://github.com/synthalorian/openshield-desktop) | Desktop GUI for OpenShield (Tauri + SvelteKit) |
| [openshield-mobile](https://github.com/synthalorian/openshield-mobile) | Android companion for OpenShield |
| [sentryclaw](https://github.com/synthalorian/sentryclaw) | Self-hosted AI code review bot with local models |
| [agentbench](https://github.com/synthalorian/agentbench) | Self-hostable benchmark runner for AI coding agents |
| [ghostbin](https://github.com/synthalorian/ghostbin) | Reverse engineering suite with LLM analysis |
