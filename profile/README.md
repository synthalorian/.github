## What we build

Open-source tools for developers, defenders and players. They run on your machine. Most need no account and no cloud.

### AI coding tools
| Repo | What it is |
|---|---|
| [openshield](https://github.com/synthalorian/openshield) | AI coding harness in Rust. Terminal first, runs on your own keys or local models. |
| [openshield-desktop](https://github.com/synthalorian/openshield-desktop) | Desktop app for OpenShield. Sessions, streaming chat, tools. |
| [openshield-mobile](https://github.com/synthalorian/openshield-mobile) | Android client for OpenShield. Pair over LAN. |
| [openshield-extension](https://github.com/Blackshield-Company/openshield-extension) | Firefox and Chrome remote for OpenShield. Send pages and selections into a session. |
| [sentryclaw](https://github.com/synthalorian/sentryclaw) | Code review bot you host yourself. Local models, no cloud, no API keys. |
| [agentbench](https://github.com/synthalorian/agentbench) | Self-hosted benchmark runner for AI coding agents. |
| [ghostbin](https://github.com/synthalorian/ghostbin) | Reverse engineering suite in Rust with optional local model analysis. |
| [bounty-mcp](https://github.com/synthalorian/bounty-mcp) | MCP server that searches paid bounties on GitHub and Opire. |

### Forensics and privacy
Software for investigators, public defenders and the people they work for.

| Repo | What it is |
|---|---|
| [beacon](https://github.com/synthalorian/beacon) | Evidence preservation and reporting guide for cybercrime victims. |
| [custody](https://github.com/synthalorian/custody) | Tamper-evident chain-of-custody log for digital evidence. |
| [docket](https://github.com/synthalorian/docket) | Local-first case file organizer for public defenders. |
| [timeline](https://github.com/synthalorian/timeline) | Evidence timeline builder for investigators and defense attorneys. |
| [exifguard](https://github.com/synthalorian/exifguard) | Batch EXIF verifier for evidence photos. |
| [blotter](https://github.com/synthalorian/blotter) | Normalizer and explorer for public crime and incident data. |
| [scamshield](https://github.com/synthalorian/scamshield) | Offline scam pattern detector for families. |
| [shieldwall](https://github.com/synthalorian/shieldwall) | Paste your setup, get a hardening checklist. |

### Dev and CLI
| Repo | What it is |
|---|---|
| [wireclaw](https://github.com/synthalorian/wireclaw) | Local HTTP proxy for API traffic. Capture, replay, inspect. Rust CLI and TUI. |
| [trackerclaw](https://github.com/synthalorian/trackerclaw) | Time tracker. Local, no cloud, no accounts. |
| [tapeworm](https://github.com/synthalorian/tapeworm) | Log analyzer in the terminal. Live tail, grep, histograms, anomaly flags. |
| [splice](https://github.com/synthalorian/splice) | Minimal Git alternative for binary assets. |
| [rift](https://github.com/synthalorian/rift) | Game asset pipeline manager. Rust CLI with a Rails dashboard. |
| [mod-release-bot](https://github.com/synthalorian/mod-release-bot) | Turns a mod release into Nexus, X and Reddit post drafts. |
